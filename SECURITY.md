# Security reports

For a vulnerability, use [GitHub's private vulnerability reporting](https://github.com/edisonmalasan/opc-rotate/security/advisories/new) if available. If it is unavailable, open an issue asking for a private reporting channel without including exploit details or secrets. There is no dedicated response-time guarantee for this preview project.

Include the affected version, a minimal reproduction with synthetic data, and the impact. Do not attach OpenCode service registration files, unredacted settings, prompts, credentials, or signing material.

The app controls machine-wide VPN routing and installs a local OpenCode CLI plugin. Its local request files can briefly contain continuation text. See [local data and removal](docs/USAGE.md#local-data-and-removal) for locations and [preview limitations](docs/USAGE.md#preview-limitations) for current verification gaps. Public VPN relays are operated by third parties.
